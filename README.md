## Clean-room Notice

This repository is a new clean-room project.

It must not copy source code, layouts, icons, strings, documentation, or branding from Seal or any other existing downloader app.

The goal is to build an original Bagback-branded application with similar general-purpose download-management concepts, implemented from scratch.

## Safe Scope

Bagback Download is intended to help users download and manage files from links and sources where they have the legal right and permission to download.

This project must not be marketed or implemented as a copyright-infringement tool.

## Planned Platforms

- Android native app
- iPhone installable web app / PWA first
- Native iOS app may be considered later after policy review

## Planned Features

- Paste URL
- Detect supported downloadable resources
- Choose audio or video when supported
- Choose quality and format when supported
- Download queue
- Progress tracking
- Retry failed downloads
- Download history
- File management
- Arabic and English interface
- Light and dark themes
- Advanced settings for experienced users
