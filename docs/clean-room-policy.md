# Clean-room Policy

Bagback Download must be developed as an original project.

## Purpose

This policy protects the project from copying code, UI, assets, text, or structure from existing applications.

## Strict Rules

Do not copy from Seal or any other downloader app:

- Source code
- UI layouts
- Icons
- Screenshots
- Text strings
- README content
- Internal architecture
- Package names
- App names or branding

## Allowed Work

Contributors may:

- Implement original features from scratch.
- Use public documentation for platform APIs.
- Use compatible open-source libraries after license review.
- Build original UI with Bagback branding.
- Discuss feature ideas at a high level.

## Contributor Statement

Every contributor should ensure their contribution is original or legally compatible with this repository license.

## Review Requirement

Before adding a dependency, check:

- License
- Source
- Whether it can be distributed in Android APKs
- Whether it can be used in a public open-source project
- Whether it affects App Store or Google Play policy compliance

## Red Flags

Reject any contribution that includes:

- Copied code from GPL projects unless the project owner explicitly chooses GPL-compatible licensing.
- Decompiled code.
- Copied UI from another app.
- Assets taken from another app without permission.
- Claims that the app downloads copyrighted content without permission.
